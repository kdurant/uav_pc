# 硬盘文件系统格式

以下所说地址单位均为：**扇区(512Byte)**

- 从硬盘地址0开始
- 偶数扇区的前32个字节用于保存文件名，不够32字节时填充0x00. 剩余的480字节填充0xee
- 基数扇区的前16个字节用于保存该文件的起始地址（8字节），结束地址（8字节），余下空间填充0x00
- 最多支持2048个文件
- 擦除操作时，硬盘空间写入0xff


| 地址 | 用途                       | 备注                            |
| ---- | -------------------------- | ------------------------------- |
| 0    | 文件0名称                  | 最长32字节                      |
| 1    | 文件0起始地址和结束地址    | 起始地址和结束地址各占用8个字节 |
| 2    | 文件1名称                  |                                 |
| 3    | 文件1起始地址和结束地址    |                                 |
| ...  | ...                        | ...                             |
| 2046 | 文件1023名称               |                                 |
| 2047 | 文件1023起始地址和结束地址 |                                 |
| ...  | 保留                       |                                 |
| 8192 | 数据区域                   |                                 |
| ...  | 数据区域                   |                                 |
