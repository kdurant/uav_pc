# 软件设计

基于 **Tauri v2 + Rust + Vue** 构建的跨平台桌面应用，通过UDP+TCP于FPGA采集卡通信, 获取采集卡状态，控制采集卡工作模式, 显示采集卡上传数据等

- [通信协议格式](./protocol_format.md)
- [具体通信指令](./pc-ps.md)
- [存储数据格式](./storge_data_format.md)


# 配置文件
- 使用与可执行文件同目录的 config.toml 作为配置文件（不存在时首次启动自动生成）
- 可通过上位机顶部工具栏的「设置」按钮打开配置界面修改全部字段；保存前会做合法性校验，
  覆盖前自动把旧文件备份为 `config.toml.bak`
- 保存**不会热更新**，需要重启上位机后生效（本机 IP/端口本身也必须在启动时绑定）
- 若程序安装在只读目录（如 `C:\Program Files`），保存会失败并提示实际路径，需要以管理员权限运行或移动程序
## 配置文件选项
```toml
[basic]
local_ip = "192.168.93.44"
local_port = 12345

remote_port = 6666

# true: 通过 UDP 广播搜索设备；false: 直接使用 device_ip 通信
broadcast_search = true
# broadcast_search = false 时使用的设备 IP
device_ip = "192.168.93.100"

[radar]
# 上位机显示名称（顶部品牌区域）
display_name = "5K 雷达"
# 激光器类型，上位机据此选择通信协议；当前支持 laser_connet / laser_5kHz
laser_type = "laser_connet"
# 自定义激光器信息（预留字段，当前不在界面显示）
laser_info = ""

[capture]
preview_coe = 1000
ref_channal = 1
save_channal = 0xff
wave_len = 6000
first_pos = 100
first_len = 200
second_pos = 400
second_len = 400
sum_value = 0
max_value = 0
pin_threshold = 1000

[ssd]
# TCP 下载 SSD 文件的分块大小（MB），仅支持 1、2、4
chunk_mb = 1

[temperature]
# 历史温度文件最多保存的点数（每 10 秒一点，180 点约 30 分钟）
save_points = 180
# 温度曲线最多显示的点数
display_points = 180
```

> `[capture]` 中的参数会在上位机启动后填入采集界面输入框（`sum_value` 对应「和阈值」，
> `max_value` 对应「值阈值」），修改后需重启上位机生效；`pin_threshold` 暂未在界面使用。
> 填入的参数不会自动下发，需在采集界面点击「应用参数」。


# 界面设计

- 左侧用于控制功能。电机，激光器，采集参数等
- 右侧显示设备状态参数
- 中间用于显示数据折线图, 要满足至少100Hz，4000数据点的刷新要求
- 顶部工具栏提供「设置」「调试」入口：设置修改 config.toml，调试菜单（需密码）内含设置向导、离线回放和点云


# 实现功能

## 局域网设备搜寻功能
1. 每次启动上位机后, 使用**local_ip**， **remote_port**，主动发送局域网广播
2. 设备会使用0x0100命令码上传设备ip地址
3. 100ms内，如果有多个设备上传ip地址，上位机会弹出选择界面

> 可在 `config.toml` 的 `[basic]` 中设置 `broadcast_search = false`，跳过广播，
> 直接使用 `device_ip` 指定的设备地址通信（适用于固定 IP 的封闭网络）。
> 此时不会发送 0x0100 广播，也不检测设备是否在线。

##  查询设备状态
使用一个checkbox来决定是否读取设备状态
- 发送的数据是0x01时，通知设备发送设备状态
- 发送的数据是0x00时，通知设备停止发送设备状态

## 解析，显示设备状态
1. 上位发送0x0102命令
2. 采集卡会响应0x0102命令, 参考./sys_status.md，解析并显示系统状态


## 数据采集，预览
1. 上位机上使用按键设置capture参数
2. 按键发送0x0300命令（0x00， 0x00, 0x00, 0x01)，通知设备上传[波形数据](./storge_data_format.md)
3. 上位机解析并显示
4. 可以通过checkbox独立选择是否显示那个通道的数据
5. 可以使用鼠标滚轮缩放预览数据
6. 勾选「基线对齐」可把每个通道空闲时的电平（中位数）归零到同一基准，4 个通道一起对齐，便于对比信号；请在无信号时开启，关闭后恢复原始数据

## SSD 文件下载
1. 通过 0x0401（transport=0x01）从设备 TCP 6666 读取 SSD 文件
2. 每次读取大小由 `config.toml` 的 `[ssd].chunk_mb` 指定，仅支持 1、2、4 MB；修改后需重启上位机生效
3. 下载前要求开启设备状态读取、SATA 已连接且设备未在存储
4. 界面显示进度和实时速度，支持取消；取消或失败会删除临时文件，不支持断点续传
5. 每次下载由用户选择保存目录

## SD 卡 GPS 文件（SFTP）
1. 通过 SSH/SFTP 读取设备 `/run/media/mmcblk1p1/`（`config.toml` 的 `[gps].dir`）下的文件
2. 文件列表显示文件名、大小和修改时间
3. 下载时选择保存目录，显示进度和实时速度，支持取消；取消或失败删除临时文件，不支持断点续传
4. 目录不存在时提示“未检测到 SD 卡，请插入 SD 卡后重试”
5. 当前测试阶段硬编码 SSH 账号（root/siom_uav），后续应改为配置/密钥

## 激光器控制
1. 通过 0x0200 透传激光器串口命令：打开/关闭、内/外触发、电流设置与状态查询
2. 通过 0x0201 设置激光重频
3. 状态查询返回箱体/泵浦温度、泵浦电流与输出功率（字段格式见 [pc-ps.md](./pc-ps.md)）

### 5kHz 激光器（laser_5kHz）
1. 协议：115200 8N1，帧格式 `55 AA 00 <cmd> ... <sum> 33 CC`
2. 支持开光/关光、内/外触发、1~5000Hz、0~6000mA、50~80µs 脉宽、清报警和状态查询
3. 设备端激光串口波特率需要配置为 115200，并经 0x0200 透传
4. 5kHz 状态帧为 50 字节，显示检测/设定频率、脉宽、LD 电流、温度、调Q延时、工作时间和错误码

## 电机控制
1. 通过 0x0f00 透传 MAXON EPOS2 命令，支持初始化、速度模式、绝对定位、回零

## 命令透传（调试）
1. 在顶部「调试」菜单（密码默认 123456）中打开「命令透传」
2. 支持命令码与设备端串口对应关系：
   - 0x0200 → /dev/ttyS1，短接 J3.1、J3.3
   - 0x0203 → /dev/ttyS3，短接 J7.1、J7.3
   - 0x0eff → /dev/ttyS3，短接 J7.1、J7.3
   - 0x0f00 → /dev/ttyS2，短接 J5.1、J5.3
3. 输入字符后点击「发送」，上位机把数据原样下发；日志区分 TX / RX，并同时显示文本与十六进制
4. 测试前需在设备端按上表短接对应引脚，发送的数据会被回环回来；等待窗口默认 600ms，可按需调整

## 设备电源
1. 重启：发送 0x0103（内容 0x01），设备约 25 秒后可重新连接
2. 关机：发送 0x0104（内容 0x01），设备约 15 秒后完成关机
3. 命令发出后上位机立即按断开处理，需重新搜索连接；操作前弹窗确认，执行中显示剩余时间

## 板载温度历史
1. 连接后每 10 秒记录一次板载温度，点击设备状态中的“板载温度”查看曲线
2. 历史点保存到可执行文件同目录的 `temperature_history.json`，启动时自动加载
3. `[temperature]` 的 `save_points` 控制文件保存点数，`display_points` 控制曲线显示点数
